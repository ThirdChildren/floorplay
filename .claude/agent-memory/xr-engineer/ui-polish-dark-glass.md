- Visual language lives in `src/ui/theme.ts` (`uiColors`, `highContrastUiColors`, new `uiTokens`: radius card 2.4 / pillMax 3.1, hairline border 0.2 (x2 in high contrast), gap 0.4, disabledOpacity 0.4). The uikitml files carry the same literal values and `tests/unit/ui-tokens.test.ts` reads them all (colours from the set, borders = token, radius = card | pill(h/2 capped) | dot). Changing a token = sed over `public/ui/*.uikitml` + theme.ts (done once with a python regex pass, property-aware: `background-color`/`color`/`border-color` map differently for the same old hex).
- RULE that made this cheap: restyle only. Box sizes/positions stay identical so `logic/*` hit rectangles, `PANEL extents` and menu-follow/pinned-follow tests are untouched. Only the menu bar changed geometry (Undo 7.2, Back 5.2, indicator 5.2, Next 5.2, Recenter 11.6; `PAGE_INDICATOR_WIDTH`, `PAGE_INDICATOR_OFFSET`, `BUTTON_SLOTS` skips the indicator cell).
- TRAP border = layout: Yoga counts `border-width` in the box model. Thinning the body border 0.4 -> 0.2 shifted rows by 0.2 cm vs the logic constants (and made the View summary text wrap at large text). Fix: keep the logic constant (0.4) and give the body `border 0.2 + padding 0.2` (top 0.6). For list rows border 0.2 + padding 0.5 = old 0.3 + 0.4. Text fit keeps its room by raising `ITEM_NAME_CLEARANCE` 0.5 -> 0.7 when `ITEM_BORDER` went 0.4 -> 0.2 (ROOM stays 16.0, so all text-fit tests hold).
- High contrast thickens the hairline in `applyPanelTheme` (all modes) and takes the extra from the same box's padding, so content does not move (tested with a fake node tree; `vi.mock('../../src/ui/fonts')` is enough to import panel-theme in vitest).
- `buttonLook` now returns `borderColor` (primary: its own colour in normal, yellow in HC). `themedColor`: accent text (`primary` as `color`) -> HC cyan; primary as `borderColor` -> HC yellow.
- Contrast tests: border must be 3:1 against surface AND secondary, selected fill 3:1 against surface, white on selected >= 4.5. That forced border `#6b7fa8` and active `#3772c2` (a "subtle" border can't be darker). The theme-contrast test used to assume a white surface: now reads `uiColors.surface`. debug-hud.uikitml / glyph-test.uikitml must also use the token colours (the test loops over every file).
- Menu bar: `Back`/`Next` are icon-only (2.6 cm lucide chevron), faint (`opacity 0.4`, `undefined` restores the inherited dimming) on first/last page via `PalmMenuPanel.setPage(page, count)` called from `menu-items.buildItems`; indicator text `strings.menu.page` is now "1/3" (cell is 5.2 cm). Label spans of prev/next were removed from the file (code is null-safe).
- Measured (emulator, `?debug=1` HUD): menu 40 calls/view, 27294 -> 27230 tris; View 35, 24550 -> 24546; Issues home 35, 24658 -> 24658. No extra boxes were added except the 5.2 cm page indicator (it replaced two label texts).
- Scratch emulator recipe still works (port 8090 copy, node_modules per-entry symlinks); RSYNC OVERWRITES the debug keys in the copy's `src/debug/menu-key.ts` (F2 View, F3 Issues, F4 list, F5 move-in, F6 home via `showIssueScreen`): keep the exclude in the sync script. `browser interact` steps: only `press` (a `wait` step with `ms` made the whole call fail silently).
